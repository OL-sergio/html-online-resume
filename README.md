# HTML Online Resume

This repository contains a simple HTML resume, hosted using GitHub Pages.

## Live Demo

You can view the resume here:  
[html-online-resume on GitHub Pages](https://ol-sergio.github.io/html-online-resume/)

## Project Structure

- `index.html` – main resume page
- `styles.css` (if present) – custom styles for the resume
- Additional assets (images, fonts, etc.), if needed

## Main Sections (Components)

The resume page typically includes:

- Header (name, job title, contact information)
- Summary / About Me
- Work Experience
- Education
- Skills
- Projects
- Links (GitHub, LinkedIn, portfolio, etc.)

You can customize or add more sections as needed.

## Frameworks and Technologies Used

- **HTML5** – structure and content of the page  
- **CSS3** – layout and visual styling  
- **Git & GitHub** – version control and code hosting  
- **GitHub Pages** – static site hosting for the online resume  

If you add more tools or libraries (for example: Bootstrap, Tailwind CSS, JavaScript), you can update this list.
